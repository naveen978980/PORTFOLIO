# Naveen Kumar — Portfolio (React + Vite + Tailwind)

## Quick Start
```bash
# 1) Install deps
npm install

# 2) Start dev server
npm run dev

# 3) Build for production
npm run build && npm run preview
```

## Tech
- React 18 (Vite)
- TailwindCSS 3 (dark mode class strategy)

## Customize
- Edit `src/data.js` to change your profile, skills, projects, etc.
- Replace images in `/public` with your own screenshots (keep same names or update `src/data.js`).
- Tweak styles in `src/styles/index.css`.
